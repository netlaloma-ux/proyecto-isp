ISP RED V2

Aplicación PWA para gestión básica de redes FTTH/GPON.

Incluye:
- OLT y PON
- Cables y cantidad de fibras
- NAP, puertos, splitter y coordenadas
- Carta de empalmes con impresión y CSV
- Clientes y ONU/ONT
- Registro OTDR
- Inventario
- Importación de KML LineString
- Grabación de trazas GPS desde el teléfono
- Exportación KML con trazas y NAP
- Respaldo/restauración JSON
- Trabajo local/offline después de cargar la aplicación

INSTALACIÓN
1. Publicar estos archivos en GitHub Pages.
2. Abrir la URL en Chrome Android.
3. Menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.

NOTA
Esta V2 es una PWA funcional. No es todavía un APK firmado nativo. Los datos se almacenan localmente en el navegador del teléfono. Para sincronización entre varios teléfonos y usuarios habrá que agregar backend/base de datos en una V3.
